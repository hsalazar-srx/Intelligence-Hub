# MES Modernization

**Status:** Active — Proposal stage  
**Approach:** Hybrid Composable Architecture  
**Timeline:** 26-week four-phase program

## Objective

Replace the current LabVIEW-based MES with a modern, composable system that eliminates single-person dependency, reduces business continuity risk, and creates the data foundation required for the AI Platform.

## Four Phases

| Phase | Focus | Outcome |
|-------|-------|---------|
| 1 | Stabilization & Documentation | Risk mitigation, knowledge transfer |
| 2 | Data Layer Modernization | Clean, structured manufacturing data |
| 3 | Composable MES Core | Modular system, M3 integration |
| 4 | AI Platform Foundation | Data pipelines ready for ML |

## Key Decisions

- **Architecture:** Hybrid composable (not monolithic commercial MES, not full custom build)
- **ERP Integration:** Infor M3 / MOVEX as source of truth
- **Change Management:** Prosci ADKAR model
